# CV site

Одностраничный сайт‑резюме на React + TypeScript + Vite.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

## Где редактировать контент

- Основная страница: `src/App.tsx`
- Проекты (карточки + мобильные мини‑галереи): `src/components/Projects.tsx`
- Скриншоты: `src/assets/projects/**`
